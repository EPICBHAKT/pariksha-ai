# 🚀 GitHub Actions Se Automatic Signed APK Download Karne Ka Guide

Maine aapke repository ke liye **GitHub Actions Workflow (`.github/workflows/build-apk.yml`)** create kar diya hai.

Ab GitHub ke powerful servers (jinme Android SDK, Java 17, aur Gradle pehle se hote hain) aapka **Real Signed APK free mein build karke download ke liye de denge**.

---

## 📋 Steps: GitHub Se APK Kaise Download Karein:

### Step 1: Code Ko GitHub Par Export / Push Karein
- Agar aapne abhi tak GitHub par push nahi kiya:
  1. AI Studio ke **Settings / Export** menu se **Export to GitHub** ya **Download ZIP** karein.
  2. Apne GitHub account par ek nayi repository banakar sara code push karein.

---

### Step 2: GitHub Actions Mein Jayein
1. Apni GitHub Repository open karein.
2. Upar menu mein **"Actions"** tab par click karein.
3. Left side mein **"Build & Release Android APK"** workflow select karein.
4. **"Run workflow"** button par click karke **"Run workflow"** dabayein (ya code push karte hi yeh apne aap shuru ho jayega).

---

### Step 3: APK Download Karein (2-3 Minutes Mein)
1. Workflow run hone ke baad green checkmark (✅) aa jayega.
2. Us run par click karein.
3. Page ke neeche **"Artifacts"** section mein aapko **`ParikshaAI_Signed_Release_APK`** milega.
4. Us par click karein aur aapka **100% genuine Signed APK download ho jayega**!

---

### 📱 Phone Mein Install Karein & Indus Appstore Par Dalein
- Download hone ke baad `.zip` extract karein jisme aapko `ParikshaAI_Signed_Release.apk` milega.
- Direct phone mein install karein aur Indus Appstore console par upload karein.
